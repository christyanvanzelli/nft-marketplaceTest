# AetherVault NFT Marketplace

Plataforma Web descentralizada de negociação de NFTs de alta fidelidade visual, desenvolvida com uma arquitetura moderna baseada em SPA, mock de API robusto via Mock Service Worker (MSW) e eventos em tempo real simulados via Socket.IO.

## 🚀 Tecnologias Utilizadas

- **Core:** React 19, TypeScript, Vite
- **Roteamento:** TanStack Router (com type-safety e rotas parametrizadas)
- **Gerenciamento de Estado & Cache:** TanStack React Query v5
- **Estilização:** Tailwind CSS v4, Radix UI & Lucide React
- **Mock & Real-Time:** Mock Service Worker (MSW) + `@mswjs/socket.io-binding`
- **Qualidade & Testes:** Playwright (Testes E2E e Regressão Visual)
